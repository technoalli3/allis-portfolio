Description

This is a 1957 Chevrolet Bel Air modeled entirely from scratch using Blender modeling software. I then textured it using Substance Painter. This was a personal project that I did to improve my modeling and texturing skills, as well as the Bel Air being my dream car. This was the first car I had ever modeled, so there are some flaws.
